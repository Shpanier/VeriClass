# VeriClass

> [English](README.md) · עברית

**עוזר בינה מלאכותית למעבדות תכנות, בשליטת המרצה.** הסטודנטים עובדים על המעבדה
בצ'אט בדפדפן עם עוזר שמכוון ולא נותן את התשובה. המרצה רואה כל שיחה בזמן אמת,
יכול/ה לעכב שאלות ולבחור או לנסח מחדש כל תשובה לפני שהיא מגיעה לסטודנט, לשמור
את כל הכיתה על אותו שלב, ולשאול שאלות קצרות כדי לבדוק הבנה.

VeriClass רץ על המחשב של המרצה (Mac, ‏Windows או Linux). הסטודנטים צריכים רק
דפדפן וקישור.

| המרצה | הסטודנטים |
|---|---|
| לוח בקרה בדפדפן: מי מחובר, כל השיחות, תור שאלות עם תשובות מוכנות לבחירה, קצב כיתתי, קורסים וסטודנטים, תרגילים | צ'אט בדפדפן: כניסה, המעבדה שלב אחר שלב, עוזר, שאלות מהמרצה. בעברית או באנגלית |

---

## התקנה

צריך כ־1.5 GB פנויים וחיבור לאינטרנט, ותו לא: ההפעלה הראשונה מתקינה את פייתון
ואת כל מה ש־VeriClass צריך, בתוך התיקייה שלו.

**macOS או Linux.** בטרמינל:

<div dir="ltr" align="left">

```bash
curl -fsSL https://raw.githubusercontent.com/Shpanier/VeriClass/main/install.sh | bash
```

</div>

**Windows.** ב־PowerShell:

<div dir="ltr" align="left">

```powershell
irm https://raw.githubusercontent.com/Shpanier/VeriClass/main/install.ps1 | iex
```

</div>

VeriClass מותקן בתיקייה `VeriClass` בתיקיית הבית ומופעל. בפעם הראשונה יורדים
כ־350 MB וזה לוקח כמה דקות; אחר כך ההפעלה לוקחת שניות. לוח הבקרה נפתח בדפדפן.

> מעדיפים להוריד בעצמכם? הורידו את ה־ZIP מ־GitHub ‏(*Code ← Download ZIP*),
> פתחו אותו בכל מקום, והפעילו כמו בהמשך.

## הפעלה

| | |
|---|---|
| **macOS** | לחיצה כפולה על `start.command` בתיקיית VeriClass. (בפעם הראשונה: קליק ימני ← *Open* ← *Open*.) |
| **Windows** | לחיצה כפולה על `start.bat`. |
| **Linux** (או כל טרמינל) | `./start.sh` |

נפתח חלון שנשאר פתוח כל עוד VeriClass רץ: **השאירו אותו פתוח במהלך השיעור**,
וסגרו אותו (או Ctrl+C) כדי לעצור. ב־macOS וב־Windows המחשב לא נרדם כל עוד
VeriClass רץ. לוח הבקרה נמצא בכתובת **http://localhost:8010**.

## הפעלה ראשונה: שני צעדים בדפדפן

1. **יצירת החשבון שלכם**: שם, שם משתמש וסיסמה. (אפשר לעשות את זה רק במחשב
   שמריץ את VeriClass.)
2. **חיבור העוזר**: בוחרים ספק ומדביקים מפתח API מהחשבון שלכם אצלו.

   - **Anthropic** (מומלץ: מפתח אחד מספיק לכל היכולות):
     <https://console.anthropic.com/settings/keys>
   - **Google Gemini**: <https://aistudio.google.com/apikey>

   המפתח נבדק מול הספק לפני שהוא נשמר, והוא נשמר רק במחשב שלכם, בקובץ `.env`
   שבתיקיית VeriClass. משלמים לספק לפי השימוש של הכיתה. אפשר להחליף אותו בכל
   רגע ב**הגדרות** (כפתור המצב בראש לוח הבקרה).

אחר כך לוח הבקרה מציג רשימה קצרה של צעדים לקראת השיעור הראשון.

## השיעור הראשון

1. **הוספת הסטודנטים.** *קורסים וסטודנטים ← ייבוא סטודנטים*: קובץ CSV (ייצוא
   משתתפים מ־Moodle או רשימה שנשמרה מ־Excel, בעברית או באנגלית). מקבלים בחזרה
   קובץ עם **שם המשתמש** ו**הסיסמה** של כל סטודנט לחלוקה. עד שקובעים סיסמה,
   הסיסמה של סטודנט היא שם המשתמש שלו.
2. **יצירת קורס** וסימון התרגילים שהסטודנטים שלו יכולים לפתוח (מצורפים שלושה
   תרגילים לדוגמה).
3. **שיתוף עם הסטודנטים** (הכפתור למעלה): לחיצה אחת יוצרת קישור ציבורי וקוד QR.
   הסטודנטים פותחים אותו בכל דפדפן ונכנסים. הקישור עובר דרך המנהרה החינמית של
   Cloudflare; בפעם הראשונה לוח הבקרה מוריד אותה בשבילכם (כ־40 MB, בלי חשבון).
   הכתובת מתחלפת בכל פעם שיוצרים אותה, אז שתפו אותה בתחילת כל שיעור.
4. **מעקב אחרי הכיתה** ב*שיעור חי*: כרטיס לכל סטודנט, השיחה שלו, וכש**מצב
   בדיקת מרצה** פועל, כל שאלה שממתינה לתשובה שלכם.

רוצים קישור שלא משתנה? ראו [Sharing with students](docs/GUIDE.md#sharing-with-students).

## הוספת תרגיל

תרגיל הוא **חבילה**: תיקייה עם כמה קובצי טקסט.

<div dir="ltr" align="left">

```
my-lab/
  exercise.yaml   what students and the tutor see: the brief, the steps
  teacher.yaml    only for you: expected answers and output checks, quiz questions
  faq.yaml        optional: common questions with ready answers
  files/          optional: what students download
```

</div>

מכווצים את התיקייה ל־ZIP וגוררים אותה ללשונית **תרגילים**. ההעלאה נבדקת קודם
ואומרת מה לתקן. אחר כך מציעים את התרגיל בקורס (*קורסים וסטודנטים*). כדי להתחיל,
העתיקו את מעבדת הדוגמה [`examples/first-lab`](examples/first-lab) וקראו את
[examples/README.md](examples/README.md). תרגילים פשוטים אפשר לכתוב גם ישירות
בלוח הבקרה (*תרגילים ← תרגיל חדש*).

## עדכון, גיבוי, מעבר למחשב אחר

- **עדכון**: מריצים שוב את שורת ההתקנה (או מורידים את ה־ZIP החדש מעל התיקייה
  הישנה). ההגדרות, מסד הנתונים והתרגילים נשמרים.
- **גיבוי או מעבר למחשב אחר**: מעתיקים שלושה דברים מתיקיית VeriClass: ‏`.env`
  (הגדרות ומפתח API), ‏`vericlass.db` (חשבונות, קורסים וכל השיחות) ו־`data/`
  (התרגילים שלכם). *הגדרות* מראה איפה הם.

## בעיות?

| מה רואים | מה עושים |
|---|---|
| "Port 8010 is used by another program" | מפעילים על פורט אחר: `./start.sh --port 8020` (ב־Windows: `start.bat --port 8020`). |
| הסטודנטים לא מצליחים לפתוח את הקישור | בודקים שהחלון שמריץ את VeriClass עדיין פתוח ושהמחשב ער, ולוחצים שוב *שיתוף עם הסטודנטים*. |
| "העוזר לא זמין כרגע" בצ'אט | כפתור המצב בלוח הבקרה אומר למה (אין מפתח, מפתח שנדחה, מגבלת תקציב). |
| הסטודנטים באותה רשת Wi-Fi, בלי קישור באינטרנט | מפעילים עם `--lan` ונותנים להם את הכתובת ש*שיתוף עם הסטודנטים* מציג תחת "באותה רשת Wi-Fi". |
| שכחתם את הסיסמה | בטרמינל בתיקיית VeriClass: `uv run python scripts/set_password.py <username>` |
