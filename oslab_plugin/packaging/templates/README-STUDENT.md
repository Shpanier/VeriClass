# OS Lab — Exam Client (student instructions)

This installs the **OS Lab** plugin into CLion and starts your exam. During the
exam you work **only inside CLion** — write your C code and ask the built‑in
tutor in the **OS Lab** panel on the right. **Leaving CLion (minimizing,
switching to a browser, or exiting full screen) is recorded and reported to
your instructor.**

## Before you start

1. **Install CLion** (JetBrains — free with a student license) and **launch it
   once** so it finishes first‑time setup.
2. Make sure you are on the **classroom network** your instructor specified.

## Install & start the exam

### macOS
1. Unzip the package you received.
2. Double‑click **`install-macos.command`**.
   - If macOS says *"unidentified developer"*: **right‑click → Open → Open**.
3. CLion opens in full screen with the **OS Lab** panel on the right.
4. Log in with the **code your instructor gave you** and begin.

### Windows
1. Unzip the package you received.
2. Double‑click **`install-windows.bat`**.
   - If Windows SmartScreen warns: **More info → Run anyway**.
3. CLion opens with the **OS Lab** panel on the right.
4. Log in with the **code your instructor gave you** and begin.

## During the exam

- ✅ Write and run your C code in CLion.
- ✅ Ask the tutor in the **OS Lab** panel (right side).
- ❌ Do **not** minimize CLion, switch to another app, or leave full screen.
  Each time you do, a red warning appears and **your instructor is notified.**

## Troubleshooting

| Problem | Fix |
|---|---|
| "Couldn't find a CLion config folder" | Launch CLion once, then run the installer again. |
| The OS Lab panel didn't open | Click **OS Lab** on the right edge of CLion. |
| "Can't reach the backend" at login | Check you're on the right network; tell your instructor. |
| CLion was already open | The installer restarts it — reopen it if needed and click **OS Lab**. |

Your instructor controls everything (which exercise, your variant, exam on/off)
from their side — you only need your login code.
