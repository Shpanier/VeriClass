# OS Lab — לקוח בחינה (הוראות לסטודנט)

החבילה מתקינה את התוסף **OS Lab** ל‑CLion ומתחילה את הבחינה. במהלך הבחינה עובדים
**רק בתוך CLion** — כותבים קוד C ושואלים את החונך המובנה בחלון **OS Lab** בצד ימין.
**יציאה מ‑CLion (מזעור, מעבר לדפדפן או יציאה ממסך מלא) נרשמת ומדווחת למרצה.**

## לפני שמתחילים

1. **התקינו את CLion** (של JetBrains — חינם עם רישיון סטודנט) **והפעילו אותו פעם
   אחת** כדי שיסיים את ההגדרה הראשונית.
2. ודאו שאתם מחוברים **לרשת הכיתה** שעליה הורה המרצה.

## התקנה והתחלת הבחינה

### macOS
1. חלצו (Unzip) את החבילה שקיבלתם.
2. לחצו פעמיים על **`install-macos.command`**.
   - אם macOS מציג *"unidentified developer"*: **לחיצה ימנית → Open → Open**.
3. CLion ייפתח במסך מלא, עם חלון **OS Lab** בצד ימין.
4. התחברו עם **הקוד שקיבלתם מהמרצה** והתחילו.

### Windows
1. חלצו (Unzip) את החבילה שקיבלתם.
2. לחצו פעמיים על **`install-windows.bat`**.
   - אם SmartScreen מזהיר: **More info → Run anyway**.
3. CLion ייפתח עם חלון **OS Lab** בצד ימין.
4. התחברו עם **הקוד שקיבלתם מהמרצה** והתחילו.

## במהלך הבחינה

- ✅ כתבו והריצו קוד C ב‑CLion.
- ✅ שאלו את החונך בחלון **OS Lab** (בצד ימין).
- ❌ **אל** תמזערו את CLion, אל תעברו ליישום אחר ואל תצאו ממסך מלא.
  בכל פעם שתעשו זאת תופיע אזהרה אדומה **והמרצה יקבל התראה.**

## פתרון תקלות

| בעיה | פתרון |
|---|---|
| "Couldn't find a CLion config folder" | הפעילו את CLion פעם אחת ואז הריצו שוב את המתקין. |
| חלון OS Lab לא נפתח | לחצו על **OS Lab** בקצה הימני של CLion. |
| "Can't reach the backend" בהתחברות | ודאו שאתם ברשת הנכונה ופנו למרצה. |
| CLion כבר היה פתוח | המתקין מפעיל אותו מחדש — פתחו שוב ולחצו על **OS Lab**. |

המרצה שולט בכל ההגדרות (התרגיל, הווריאנט שלכם, הפעלת/כיבוי מצב בחינה) מהצד שלו —
אתם צריכים רק את קוד ההתחברות.
